# 앵챗추출기 (v2.13.0)

> **RP 대화 전체 내보내기 및 백업 도구 (Chrome Extension)**  
> Caveduck, TeapotChat, Rofan.ai, Uumm.ai 등 다양한 롤플레잉(RP) 채팅 플랫폼에서 긴 대화를 누락 없이 .txt, .md, .html, .pdf로 안전하게 내보냅니다.

---

## ✨ 주요 기능

- ⚡ **자동 스크롤 및 지연 로딩 캡처**: 가상 스크롤(Virtual Scroll)로 인해 화면 밖으로 사라지는 대화도 순차적 스위프와 진동 알고리즘으로 누락 없이 수집
- 🎨 **Cloud Dancer & Emil Kowalski UI**: 차분하고 직관적인 전용 커스텀 드롭다운 셀렉트 UI와 부드러운 마이크로 인터랙션
- 📑 **다양한 내보내기 형식**: 
  - **텍스트 (.txt)**: 메모장, 프롬프트 입력 및 백업 최적화
  - **마크다운 (.md)**: 서식 보존
  - **HTML (.html)**: 독립 뷰어로 바로 읽기 가능
  - **PDF (.pdf)**: 페이지 분할 인쇄 및 저장
- 📦 **지능형 분할 및 ZIP 생성**: 대용량 대화를 글자 수(600,000자 등) 또는 메시지 개수(50개 등) 단위로 자동 분할하여 ZIP으로 패키징
- 🔍 **토글 펼침 추출**: 접힌 위젯, 상태창, 설명 영역까지 자동 펼침 지원
- ⏱️ **실시간 5단계 속도 조절**: 사이트 로딩 속도에 맞춰 느림(안전)부터 초고속까지 실시간 가변 조절

## 🚀 설치 방법

### 간단 설치 (30초)
1. GitHub 저장소 우측 상단의 **Code ➔ Download ZIP** (또는 릴리스/Notion 페이지의 rp-exporter.zip)을 다운로드합니다.
2. 다운로드한 rp-exporter.zip의 압축을 풉니다 (rp-exporter 폴더 생성).
3. Chrome 주소창에 chrome://extensions 입력 후 접속합니다.
4. 우측 상단의 **개발자 모드**를 켭니다.
5. 좌측 상단의 **[압축해제된 확장 프로그램 로드]**를 클릭하고, 압축을 푼 rp-exporter 폴더를 선택합니다.
6. Chrome 툴바의 퍼즐 아이콘에서 앵챗추출기를 **고정(📌)**하여 사용합니다.

---

## 🔄 업데이트 방법

1. 새로운 최신 rp-exporter.zip을 다운로드합니다.
2. 기존 rp-exporter 폴더에 압축을 덮어씁니다.
3. chrome://extensions에서 앵챗추출기 카드의 **새로고침(↻)** 버튼을 누르면 업데이트가 즉시 완료됩니다.

## ❓ 문제 해결 (FAQ)

### 아이콘을 눌렀는데 빨간 느낌표가 뜨며 작동하지 않아요

**사이트 액세스 권한 설정**을 확인해주세요.

1. Chrome 주소창에 `chrome://extensions` 입력 후 접속
2. 앵챗추출기 카드에서 **세부정보** 클릭
3. **사이트 액세스** 항목을 **'모든 사이트'** 로 변경
4. 채팅방 탭에서 아이콘을 다시 클릭

> v2.11.1부터 권한 부족 시 실제 원인이 배지에 표시됩니다.
> "채팅 탭에서 열어주세요" 메시지가 더 이상 나오지 않습니다.

### 특정 브라우저 내부 페이지(chrome://, 확장 프로그램 스토어 등)에서는 작동하지 않나요?

네, 브라우저 보안 정책상 해당 페이지에는 스크립트 주입이 불가능합니다.
채팅이 열린 일반 웹 페이지 탭에서 사용해주세요.
