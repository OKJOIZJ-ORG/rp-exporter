# 앵챗추출기 (AengChat Exporter) v2.11.7

현재 탭의 채팅 화면을 스크롤하며 불러온 텍스트를 수집해 저장하도록 구현된 Chrome Manifest V3 확장 프로그램입니다.


## 구현된 기능

- **자동 추출**: 이전 메시지 로딩, 화면 순회, 저장 흐름이 한 버튼에 연결되어 있습니다.
- **수동 추출**: `① 전체 로딩` 후 `② 추출·저장`을 따로 실행할 수 있습니다.
- **파일 형식**: TXT, Markdown, HTML 다운로드를 지원합니다.
- **PDF 저장**: 브라우저 인쇄 대화상자를 열며, 사용자가 인쇄 대상에서 PDF를 선택합니다.
- **분할 저장**: 기본값은 `분할 안 함`입니다. AI 서비스에 파일을 첨부할 때 한 파일의 허용량을 넘는 경우, 첫 추출 완료 화면의 전체 대화 개수·약 글자 수를 보고 글자 수 또는 수집 블록 수 기준을 정해 ZIP으로 다시 저장합니다.
- **추출 조절**: 파일명, 접힌 `details` 펼치기, 추출 속도를 설정할 수 있습니다.
- **구조 자동 감지**: 도메인 이름만 보지 않고 `[data-turn-key]`, 화자 마커, 정방향 스크롤 구조가 함께 확인되면 안정형 상단 로더를 자동 선택합니다. `column-reverse` 계열은 기존 역방향 로더를 유지합니다.
- **TeapotChat 대응**: 실제 스크롤바를 끌듯 단계적으로 하단 자동 추적을 해제한 뒤, 한 화면보다 작은 간격으로 위치를 확인하며 최상단에 접근합니다. 상단에서는 이전 턴이 붙을 시간을 기다리고, 높이가 늘어나면 다시 천천히 올라갑니다. 빠른 속도 설정에서도 이 안정 대기 시간은 줄이지 않습니다. 첫 사용자 입력보다 앞선 독립 도입부(`start-…` 메시지)를 먼저 포함합니다.
- **Caveduck 대응**: 카드 안의 상태창·위젯용 `<details>` 수가 아니라 `chat-message-*` 상위 카드 수를 메시지 수로 사용합니다. 집계와 추출이 같은 카드 배열을 공유해 턴 수 과대 표시와 상위 화자 정보 누락을 막습니다.
- **현재 로드 범위 순회**: `② 추출·저장`은 현재 보이는 한 화면에서 시작하지 않습니다. 현재 DOM에 로드된 대화 범위의 한쪽 끝에서 반대쪽 끝까지 순회하며, 아직 서버에서 불러오지 않은 과거 대화는 `① 전체 로딩`이 선행되어야 포함됩니다.
- **크기 조절 패널**: 우측 하단 위치를 유지한 채 상하좌우 변과 네 꼭짓점을 드래그해 패널 전체를 같은 비율로 조절할 수 있습니다. 작은 뷰포트에서는 처음부터 잘리지 않도록 자동 축소합니다.
- **직관적인 진행 안내**: 현재 URL의 호스트명과 감지된 로딩 방식을 표시합니다. 하단 상태는 별도 블록에서 핵심 사실만 안내하고, 버튼 경로는 굵은 캡슐로 구분합니다. 접힌 토글 옵션에는 호스트 사이트 스타일에 영향받지 않는 커스텀 체크박스를 사용합니다. 정상적으로 처리한 상단 로딩 경고는 패널에만 표시하며 Chrome 확장 프로그램 오류 목록에는 새 오류로 기록하지 않습니다.

## v2.11.4 변경 내역 — 2026.10.01

- 상단 로딩의 `변화 없음` 종료 기준을 8회에서 4회로 줄였습니다.
- 서로 다른 메시지의 내용이 같거나 한 글자여도 수집하도록 보완했습니다. 스크롤할 때 화면에서 사라지는 대화를 누적하고, 열린 Shadow DOM 안의 대화도 탐색합니다.
- 패널을 닫으면 진행 중인 작업을 취소합니다. 다시 열 때 이전 패널의 이벤트와 인쇄용 임시 화면을 정리합니다.
- 높이가 낮은 화면에서도 닫기 버튼이 화면 안에 들어오도록 자동 축소를 보완했습니다. 기존 드래그 크기 조절도 사용할 수 있습니다.
- 저장 안내를 실제 동작에 맞춰 `다운로드를 요청했습니다`와 `인쇄를 요청했습니다`로 바꿨습니다.

## 설치 — PC Chrome

[최신 공개 ZIP 다운로드](https://raw.githubusercontent.com/OKJOIZJ-ORG/rp-exporter/main/rp-exporter.Public.zip)를 눌러 파일을 받습니다.

1. `rp-exporter.Public.zip`을 압축 해제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 개발자 모드를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`에서 압축을 푼 폴더 중 `manifest.json`이 있는 폴더를 선택합니다.
5. RP 채팅방을 새로고침하고 확장 프로그램의 앵챗추출기 아이콘을 눌러 실행합니다. 패널 제목 옆에 `v2.11.7`가 표시되는지 확인하세요.

## 설치 — iPhone·iPad Orion

1. App Store에서 [Orion Browser by Kagi](https://apps.apple.com/kr/app/orion-browser-by-kagi/id1484498200)를 설치합니다.
2. 위의 공개 ZIP을 내려받아 파일 앱에 저장합니다. **ZIP의 압축은 풀지 않습니다.**
3. Orion의 `••• → 설정 → 확장 프로그램`에서 Chrome 확장 설치를 허용합니다.
4. `••• → 확장 프로그램 → ＋ → 파일에서 설치`에서 ZIP 자체를 선택합니다.
5. Orion 안에서 RP 채팅방을 열고 `••• → 앵챗추출기`로 실행합니다. 메뉴에 바로 없으면 `확장 프로그램 → 앵챗추출기`를 확인하세요.

Orion의 확장 지원은 개발 중입니다. 이번 버전의 iOS 실기·PDF 저장은 별도 확인이 필요합니다.

## ZIP으로 설치한 확장 업데이트

- **Chrome:** 새 ZIP을 내려받아 기존 설치 폴더에 압축을 풀어 덮어쓴 뒤, `chrome://extensions`의 앵챗추출기 카드에서 새로고침(↻)을 누릅니다.
- **Orion:** 새 ZIP을 압축 해제하지 않고 `파일에서 설치`로 다시 불러옵니다.
- 채팅방을 새로고침한 뒤 패널 제목의 `v2.11.7`를 확인합니다. 이 ZIP 설치 경로는 자동 업데이트가 아닙니다.

## AI 첨부용 파일 분할

1. 처음에는 기본값인 `분할 안 함`으로 추출합니다.
2. 완료 후 패널 하단의 `대화 n개 · 약 n자` 표시를 확인합니다. 이 통계는 추출 파일 본문에 자동으로 적히지 않습니다. 최신 Windows 11 메모장으로 파일을 열면 창 아래쪽 상태 표시줄(일반적으로 왼쪽 아래)에서 전체 글자 수를 쉽게 확인할 수 있습니다. 표시되지 않는 구형 메모장에서는 다른 편집기의 문자 수 기능을 사용하세요.
3. 한 파일이 AI 서비스의 첨부 제한을 넘으면 `글자 수마다` 또는 `메시지 개수마다`를 선택합니다.
4. 원하는 파일 개수가 N개라면 `전체 글자 수 ÷ N` 또는 `전체 대화 개수 ÷ N`을 올림한 값을 시작점으로 입력합니다. 서비스 제한과 정확히 맞추기보다 여유 있게 작게 잡는 편이 안전합니다.
5. 다시 추출하면 여러 파일을 담은 ZIP이 내려받아집니다. 압축을 풀고 각 파일의 실제 크기가 첨부 대상의 제한 안에 드는지 확인합니다.

글자 수, 파일 바이트, AI 토큰 수는 서로 같은 단위가 아닙니다. 또한 긴 메시지 한 개가 설정값보다 크면 해당 파일은 기준값을 넘을 수 있으므로, 생성된 파일 크기를 마지막에 직접 확인하세요.

## 확인이 필요한 제한

- 추출 결과는 사이트의 화면 구조와 지연 로딩 방식에 영향을 받습니다. 저장 후 원문과 대조해 누락 여부를 확인하세요.
- 안정적인 메시지 ID가 없는 화면 재구성·실시간 생성에서는 중복이나 일부 내용이 남을 수 있습니다. 닫힌 Shadow DOM 안의 대화는 탐색할 수 없습니다.
- 패널 입력값은 영구 저장되지 않으며, 패널이 새로 만들어지면 기본값으로 돌아갑니다.
- 플랫폼별 자동 브라우저 테스트는 현재 포함되어 있지 않습니다.
