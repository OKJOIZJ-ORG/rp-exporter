# 앵챗추출기 (AengChat Exporter) v2.11.1

AI 롤플레잉 채팅(케이브덕 등) 대화 내역 전체를 추출하여 .txt / .md / .html / .pdf 파일 또는 ZIP 분할 압축으로 다운로드할 수 있는 Chrome 확장 프로그램입니다.

## 기능 요약
- **자동 추출**: 버튼 한 번으로 전체 대화 로딩 및 다운로드
- **수동 로딩/추출**: ① 전체 로딩 후 ② 추출·저장
- **분할 저장**: 글자 수 / 메시지 개수 기준 자동 ZIP 분할
- **커스텀 파일명 및 속도 조절**: 사용자 편의 기능 제공
